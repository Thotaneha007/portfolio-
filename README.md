## 🚀 How to Run and View the Portfolio

Since this website is built with clean, modern **Vanilla HTML5, CSS3 (Custom Glassmorphism), and JavaScript (ES6)**, there are no complicated installation steps or framework builds. You can run and view it instantly using either of the methods below:

### Option 1: Direct Double-Click (Quickest)
1. Navigate to this folder (`portfolio_website`).
2. Double-click the **`index.html`** file.
3. It will open immediately in your default web browser (Edge, Chrome, Safari, Firefox) with all styles, animations, active resume downloads, and research paper links fully functional.

### Option 2: Live Server (Recommended for Development)
If you are using **VS Code**, you can run a local server for real-time live reloading:
1. Open this `portfolio_website` directory in **VS Code**.
2. Click on the **"Go Live"** button at the bottom-right corner of the editor (requires the **Live Server** extension).
3. The site will launch automatically at `http://127.0.0.1:5500/index.html`.

### Option 3: Python Web Server
You can quickly run a lightweight web server from your terminal:
```bash
# In the portfolio_website directory, run:
python -m http.server 8000
```
Then, open your browser and go to `http://localhost:8000`.
